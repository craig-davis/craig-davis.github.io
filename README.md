# There4.io

Craig Davis's personal site: field notes about software, machines, making, bikes, books, and life.

## Maintain the site

- [Care and feeding](docs/modernization/CARE-AND-FEEDING.md) — write and update articles, prepare photographs and WebPs, preview, verify, and deploy
- [Voice and tone](docs/modernization/VOICE-AND-TONE.md) — editorial guidance for review and AI-assisted drafting
- [Working TODO](docs/modernization/TODO.md) — prioritized follow-up work and article backlog
- [Deployment contract](docs/modernization/DEPLOYMENT.md) — DigitalOcean and production details
- [Verification](docs/modernization/VERIFICATION.md) — build gates and baseline policy

Common commands:

```sh
bin/serve          # local site on http://127.0.0.1:4001/
bin/prepare-image img/headers/example.jpg
bin/verify
```
